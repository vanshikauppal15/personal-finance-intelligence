# Personal Finance Intelligence

A full-stack Data Science web application that analyzes bank/UPI transaction
statements to provide automatic categorization, anomaly detection, and
spending forecasts.

## Status

🚧 Under active development — Phase 0 complete.

## Tech Stack

- Backend: Flask
- Database: PostgreSQL
- Data Science: Pandas, scikit-learn, statsmodels
- Frontend: HTML/CSS/JS, Bootstrap, Chart.js
